# GSE52778 Gene Expression Data Quality, Reliability & Reproducibility Project

This project is a reproducible RNA-seq analysis and reporting workflow using the public GEO dataset GSE52778. It investigates how dexamethasone affects gene expression in human airway smooth-muscle cells while accounting for donor-specific baseline differences.

The project combines Python metadata validation, R/Bioconductor analysis, DESeq2 differential-expression modelling, paired-vs-unpaired sensitivity analysis, GO Biological Process enrichment, SQLite relational data modelling, analytical SQL views, Power BI reporting, Git version control and `renv` dependency management.

## Dataset

GEO accession: `GSE52778`

The core analysis uses 8 RNA-seq samples from 4 human airway smooth-muscle donor/cell lines. Each donor contributes one untreated and one dexamethasone-treated sample.

The count data are loaded from the Bioconductor `airway` package.

This project starts from the real gene-count matrix rather than FASTQ files. Therefore it performs count-level analysis and does not claim to run FastQC, MultiQC, alignment or featureCounts.

## Scientific question

Does dexamethasone alter gene expression after controlling for baseline differences between donor/cell lines?

Primary DESeq2 model:

`\~ cell + dex`

Sensitivity model:

`\~ dex`

The `cell` term acts as a blocking factor because each donor contributes both an untreated and treated sample.

## Key results

The original count matrix contains 63,677 genes across 8 samples.

Filtering rule:

`count >= 10 in at least 4 samples`

Genes retained after filtering:

`16,139`

PCA on variance-stabilised counts showed:

`PC1 = 48.1%`

`PC2 = 23.5%`

Sample-to-sample correlations were approximately:

`0.961 - 0.989`

No sample was removed from the primary analysis.

Primary DESeq2 results at adjusted p-value < 0.05:

`Significant genes: 4,081`

`Upregulated: 2,190`

`Downregulated: 1,891`

Using adjusted p-value < 0.05 together with `|log2FoldChange| >= 1`:

`>=2-fold significant genes: 951`

`>=2-fold upregulated: 490`

`>=2-fold downregulated: 461`

The paired and unpaired models produced highly concordant effect-size estimates:

`Pearson r approximately 0.995`

The paired model identified 4,081 significant genes, while the simplified unpaired model identified 2,773.

Significance overlap:

`Both models: 2,674`

`Paired only: 1,407`

`Unpaired only: 99`

`Neither: 11,959`

This shows that treatment-effect estimates are highly stable, while donor adjustment improves statistical precision.

## GO Biological Process enrichment

GO enrichment is performed separately for the 490 >=2-fold upregulated and 461 >=2-fold downregulated genes.

The background universe contains all 16,139 genes tested in the primary DESeq2 analysis.

After Ensembl-to-Entrez mapping:

`Background genes mapped: 14,105`

`Upregulated genes mapped: 460`

`Downregulated genes mapped: 441`

Full GO BP results:

`Upregulated terms: 63`

`Downregulated terms: 270`

After redundancy reduction using semantic similarity:

`Upregulated terms: 37`

`Downregulated terms: 94`

Major upregulated themes include extracellular-matrix organisation, muscle-related processes, hormone-response pathways and vascular processes.

Major downregulated themes include cell projection and morphogenesis, signalling, ion transport and circulatory-related processes.

GO terms are hierarchical and overlapping and should not be interpreted as independent biological effects.

## Scope and limitations

This is a count-level RNA-seq reproducibility project. It does not claim to reproduce upstream FASTQ processing such as FastQC, MultiQC, read alignment or feature counting.

The included `Dockerfile` and `workflow/main.nf` are reproducibility/prototyping scaffolding and are not claimed to be fully validated production workflows.

GO enrichment is an over-representation analysis and supports biological interpretation rather than causal inference.

The Power BI native scatter visual may apply data reduction when displaying large numbers of points. The R-generated volcano plot remains the complete analysis figure.
