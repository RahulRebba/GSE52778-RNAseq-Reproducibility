# Reproduce GSE52778 Project on Windows

This project reproduces a count-level RNA-seq analysis of GEO dataset GSE52778 using Python, R/Bioconductor, SQLite and Power BI. Conda is used for Python and command-line tools, while standalone R 4.6.0 with `renv` is used for R/Bioconductor packages.

Project folder used during development:

`C:\\Users\\rahul\\Data Analysis\\GSE52778_Reproducible_Project`

Open Miniconda Prompt and move to the project folder:

`cd /d "C:\\Users\\rahul\\Data Analysis\\GSE52778_Reproducible_Project"`

Create the Conda environment on a new machine with:

`conda env create -f environment.yml`

Then activate it:

`conda activate gse52778`

Restore the R environment recorded in `renv.lock` with:

`"C:\\Program Files\\R\\R-4.6.0\\bin\\Rscript.exe" -e "renv::restore()"`

Check the R environment with:

`"C:\\Program Files\\R\\R-4.6.0\\bin\\Rscript.exe" -e "renv::status()"`

The validated project reports:

`No issues found -- the project is in a consistent state.`

Run the analysis in the following order:

`python scripts\\01_validate_metadata.py`

`"C:\\Program Files\\R\\R-4.6.0\\bin\\Rscript.exe" scripts\\02_airway_deseq2.R`

`"C:\\Program Files\\R\\R-4.6.0\\bin\\Rscript.exe" scripts\\03_sensitivity_analysis.R`

`"C:\\Program Files\\R\\R-4.6.0\\bin\\Rscript.exe" scripts\\04_go_enrichment.R`

`python scripts\\05_load_sqlite.py`

The primary DESeq2 model is `\~ cell + dex`, which accounts for donor/cell-line differences while estimating the dexamethasone treatment effect. The sensitivity model is `\~ dex`.

The original airway count matrix contains 63,677 genes across 8 samples. Genes are retained when they have a count of at least 10 in at least 4 samples, leaving 16,139 genes for analysis. The primary DESeq2 analysis identifies 4,081 genes with adjusted p-value < 0.05, including 2,190 upregulated and 1,891 downregulated genes. Applying adjusted p-value < 0.05 together with `|log2FoldChange| >= 1` identifies 951 genes with at least a two-fold expression change: 490 upregulated and 461 downregulated.

The paired and unpaired models show highly concordant log2 fold-change estimates with Pearson correlation approximately 0.995, while donor adjustment improves statistical precision.

GO Biological Process enrichment is performed using the 490 >=2-fold upregulated and 461 >=2-fold downregulated genes, with all 16,139 tested genes used as the background universe. In the validated run, 14,105 background genes, 460 upregulated genes and 441 downregulated genes mapped to Entrez IDs. The analysis produced 63 enriched GO BP terms for upregulated genes and 270 for downregulated genes. After semantic-similarity redundancy reduction using `simplify()`, 37 upregulated and 94 downregulated terms remained. Some Ensembl-to-Entrez mapping warnings are expected.

The SQLite database is generated by:

`python scripts\\05_load_sqlite.py`

This creates:

`results\\generated\\gse52778_project.db`

The relational model contains the tables `study`, `sample`, `sample_qc`, `gene`, `analysis_run`, `analysis_result`, `go_enrichment` and `analysis_summary`. Reporting views are `vw_sample_qc`, `vw_primary_de_results`, `vw_sensitivity_comparison` and `vw_go_enrichment`. The generated SQLite database is excluded from Git because it can be rebuilt from the source scripts and generated analysis files.

The completed Power BI dashboard is:

`powerbi\\GSE52778_PowerBI_Dashboard_Final.pbix`

It contains four pages: Project Overview, QC & Sensitivity, GO Enrichment and Differential Expression.

Main generated analysis files are stored under:

`results\\generated\\`

Important outputs include `01_library_sizes_manual.png`, `02_pca_manual.png`, `04_ma_plot_manual.png`, `06_volcano_plot_polished_manual.png`, `07_top_gene_heatmap_manual.png`, `08_sensitivity_foldchange_comparison.png`, `09_go_bp_upregulated_dotplot.png`, `10_go_bp_downregulated_dotplot.png`, `deseq2_results_annotated_manual.csv`, `deseq2_results_unpaired_manual.csv`, `go_bp_upregulated_simplified.csv`, `go_bp_downregulated_simplified.csv` and `analysis_summary_manual.csv`.

This project starts from the real gene-count matrix supplied by the Bioconductor `airway` package. It therefore does not claim to perform FASTQ-level processing such as FastQC, MultiQC, read alignment or feature counting. The `Dockerfile` and `workflow\\main.nf` files are included as reproducibility/prototyping scaffolding and are not claimed to be fully validated production workflows.
