# Power BI Reporting Guide - GSE52778

The completed Power BI report is:

`GSE52778_PowerBI_Dashboard_Final.pbix`

The dashboard is the reporting layer for the validated RNA-seq, sensitivity, GO enrichment and SQL results. Power BI is not used to perform the DESeq2 statistical analysis.

## Data source

The final dashboard uses curated reporting datasets generated from the SQLite data layer:

`analysis_summary`

`vw_sample_qc`

`vw_primary_de_results`

`vw_sensitivity_comparison`

`vw_go_enrichment`

The SQLite database is generated with:

`python scripts/05_load_sqlite.py`

and stored locally as:

`results/generated/gse52778_project.db`

The database itself is excluded from Git because it can be rebuilt reproducibly.

Power BI was connected to SQLite using Python, `sqlite3` and `pandas`.

Because Python interpreter paths and database paths depend on the local computer, another user may need to update these paths when refreshing the report.

## Report pages

The completed report contains four pages.

### 1. Project Overview

This page summarises the primary DESeq2 analysis.

Main KPI values:

`Samples analysed: 8`

`Donors: 4`

`Genes after filtering: 16,139`

`Significant genes: 4,081`

`>=2-fold significant genes: 951`

The page also contains the distribution of result classes and the Top 10 upregulated genes.

Significance is defined as:

`adjusted p-value < 0.05`

The >=2-fold threshold is:

`|log2FoldChange| >= 1`

### 2. QC & Sensitivity

This page contains the RNA-seq PCA and the paired-vs-unpaired sensitivity comparison.

PCA variance:

`PC1 = 48.1%`

`PC2 = 23.5%`

The sensitivity analysis compares:

`Paired model: \~ cell + dex`

`Unpaired model: \~ dex`

Significance overlap:

`Both: 2,674`

`Paired only: 1,407`

`Unpaired only: 99`

`Neither: 11,959`

The paired and unpaired log2 fold-change estimates are highly concordant:

`Pearson r approximately 0.995`

The interpretation is that treatment-effect estimates are highly stable while donor adjustment improves statistical precision.

### 3. GO Enrichment

This page reports GO Biological Process enrichment separately for >=2-fold upregulated and downregulated genes.

The charts display the Top 10 enriched terms selected by adjusted p-value.

Bar length represents gene count rather than statistical significance.

The validated enrichment analysis produced:

`37 simplified upregulated GO BP terms`

`94 simplified downregulated GO BP terms`

Major upregulated themes include extracellular-matrix organisation, muscle-related processes and hormone-response pathways.

Major downregulated themes include morphogenesis, signalling, ion transport and circulatory-related processes.

GO terms are hierarchical and overlapping and should not be interpreted as independent effects.

### 4. Differential Expression

This page contains an interactive volcano plot and the Top 10 downregulated genes.

Volcano plot axes:

`X = log2 fold change`

`Y = -log10 adjusted p-value`

Reference thresholds:

`log2FoldChange = -1`

`log2FoldChange = +1`

`adjusted p-value = 0.05`

A calculated Power BI field is used for the Y-axis:

`neg_log10_padj = -LOG10(padj)`

The R-generated volcano plot in `results/generated/06_volcano_plot_polished_manual.png` remains the complete analysis figure. The native Power BI scatter visual may apply data reduction when displaying large datasets.

## Data model

The curated reporting views are intentionally used as standalone reporting datasets.

No relationships are required between the imported reporting views because the SQL layer already provides denormalised datasets for each reporting purpose.

This avoids unnecessary many-to-many or blank-key relationship problems in Power BI.

## Important note

The dashboard reports results generated by the reproducible Python, R and SQL workflow.

Scientific conclusions should be based on the validated analytical outputs rather than on formatting or calculations performed only inside the Power BI report.
